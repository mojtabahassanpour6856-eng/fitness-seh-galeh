محدودیت کاتالوگ

  • کاتالوگ source برای چهارسر فقط QUADRICEPS_LEFT/RIGHT دارد؛ شناسه مجزایی برای rectus femoris و vasti تعریف نشده است.
  • برای ذوزنقه‌ای فقط TRAPEZIUS_LEFT/RIGHT وجود دارد؛ بخش‌های فوقانی، میانی و تحتانی شناسه مستقل ندارند.
  • نوع داده MusclePath شامل group، side، d و id اختیاری است؛ parent/child یا سلسله‌مراتب عضلانی در این مدل تعریف نشده است.
  • در بعضی نماها چند مسیر از یک شناسه مشترک استفاده می‌کنند؛ در نتیجه ID به‌تنهایی مسیر قابل انتخاب را یکتا نمی‌کند.

تصمیم فنی فعلی

  1. کلید داخلی یکتا برای هر مسیر نگه داشته شود؛ هرگز id منبع به‌عنوان کلید اصلی استفاده نشود.
  2. برای چهارسر و ذوزنقه‌ای، فعلاً زیرناحیه‌های جدید فقط پس از ترسیم هندسه مستقل و تأیید اطلس ساخته شوند.
  3. مسیرهای دارای شناسه تکراری/مفقود تا زمان حل منشأ هندسه، در وضعیت بازبینی باقی بمانند.
  4. این ممیزی فقط کیفیت ساختار داده را بررسی می‌کند؛ صحت آناتومی را تأیید نمی‌کند.
