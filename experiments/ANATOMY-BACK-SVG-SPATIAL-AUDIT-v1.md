# ممیزی هندسی اولیه عضلات پشت — Trapezius، Rhomboids، Latissimus و Lower Back — v1

تاریخ: 2026-11-28  
شاخه: `experiment/anatomy-smart-rebuild-20261127`  
منبع: `experiments/anatomy-smart-prototype.html`  
روش: استخراج مستقیم آرایه `DATA` و محاسبه bounding box تقریبی از مختصات اعداد موجود در رشته‌های SVG path. این محاسبه، رندر یا تحلیل توپولوژیک مسیر نیست.

## 1) محدودیت روش

Bounding box با خواندن زوج‌های عددی رشته path به‌دست آمده است. این روش برای تشخیص گستره مکانی و مقایسه تقریبی مفید است، اما:
- جایگزین parser کامل SVG نیست؛
- برای منحنی‌ها ممکن است دقیقاً extrema هندسی را ندهد؛
- درباره اتصال، هم‌پوشانی واقعی، پوشیدگی یا صحت آناتومیک path حکم قطعی نمی‌دهد؛
- رندر مرورگر و بازبینی بصری در این مرحله انجام نشده است.

ViewBox پیش‌نمایش: `0 0 1024 1536`؛ خط میانی تقریبی بوم در x=512.

## 6) ایراد داده‌ای مشترک

برای تمام pathهای چهار گروه بررسی‌شده در نمای پشت، مقدار فیلد `side` برابر `CENTER` است؛ حتی زمانی که ID شامل LEFT یا RIGHT است. بنابراین مصرف‌کننده داده نباید به فیلد `side` فعلی برای تعیین laterality اعتماد کند. همچنین:
- Trapezius در هر نما IDهای تکراری دارد؛
- Rhomboids، Latissimus و Lower Back در هر نما IDهای یکتا دارند؛
- هیچ pathی با این گزارش به anatomy entity جدید یا بخش عضلانی مستقل تبدیل نمی‌شود.

## 7) وضعیت و اقدام بعدی

- Trapezius: چهار path در هر نما؛ mapping ناحیه‌ای و pairing مسدود تا رندر و بررسی هندسی.
- Rhomboids: دو path چپ/راست از نظر شناسه و موقعیت؛ تفکیک major/minor تأیید نشده.
- Latissimus: دو path چپ/راست از نظر شناسه و موقعیت؛ هندسه هنوز بازبینی بصری نشده.
- Lower Back: دو path ناحیه‌ای؛ انتساب به عضله/گروه عمقی مشخص ممنوع تا بررسی.
- فیلد `side` برای این چهار گروه نیازمند اصلاح در نسخه داده آینده است؛ در این commit منبع اصلی دست‌کاری نشده است.

## 8) کارهای انجام‌نشده

- رندر SVG در مرورگر یا موتور SVG؛
- مقایسه تصویری با اطلس مرجع؛
- تحلیل path intersection/occlusion؛
- اعتبارسنجی علمی مرزها توسط متخصص آناتومی؛
- اصلاح ID و side در داده اجرایی.

این سند ممیزی مختصاتی اولیه است، نه تأیید آناتومیک.
